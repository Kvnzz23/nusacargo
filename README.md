# NusaCargo Control Tower
NusaCargo Control Tower merupakan dashboard internal perusahaan logistik yang digunakan untuk memantau pengiriman kontainer antar pulau secara harian.

NusaCargo mengelola pengiriman melalui 6 pelabuhan utama. Saat ini, tim operasional masih menggunakan spreadsheet yang dikirim melalui surel. Kondisi tersebut menyebabkan informasi mengenai keterlambatan pengiriman sering diketahui beberapa jam setelah kejadian.

Dashboard ini dirancang sebagai sistem terpusat untuk menampilkan status pengiriman terkini, menyoroti risiko keterlambatan, serta membantu petugas memperbarui status pengiriman dari lapangan.
